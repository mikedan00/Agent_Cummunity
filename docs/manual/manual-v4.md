# 버전 4 설명서 — 브라우저끼리 직접 연결되는 P2P

**위치:** `v4/` · **실행:** 로비 서버는 HF Space, 대화는 각 브라우저 · **저장:** 각 브라우저

로비 서버는 **연결할 때만** 쓰고, 대화는 참여자의 브라우저끼리 직접 주고받습니다. 호스트가 나가면 **남은 사람 중 한 명이 자동으로 이어받습니다.** 노트북, PC, 휴대폰 어떤 기기든, 데이터망이든 Wi-Fi든 브라우저로 접속하면 됩니다.

---

## 1. 실행 방법

### HF Space 배포 (권장 — 다른 기기에서 쓰려면 https가 필요)
1. **Space 만들기:** https://huggingface.co/new-space 에서 만듭니다.
   - 이름: `agent-community-p2p`
   - SDK: **Docker → Blank**
   - Hardware: **CPU basic**
   - Visibility: **Public**
2. **Space Secrets (모두 선택):**

   | 이름 | 설명 |
   |---|---|
   | `LOBBY_SIGNING_KEY` | **권장.** 입장 순서 서명 키(PEM). 없으면 로비가 재시작할 때마다 바뀝니다. 아래 명령으로 만듭니다 |
   | `HF_TOKEN` | 운영자 토큰. 넣으면 호스트가 "운영자 토큰"을 고를 수 있음 |
   | `OPERATOR_AI_PER_HOUR`, `OPERATOR_AI_PER_DAY` | 운영자 토큰 한도 (기본 IP당 시간 60회, 하루 2,000회) |
   | `HF_MODELS` | 모델 목록 (쉼표로 구분) |
   | `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL` | TURN 중계 서버 (없어도 로비 중계로 접속됨) |
   | `STUN_URLS` | 기본 `stun:stun.l.google.com:19302` |

   `LOBBY_SIGNING_KEY` 만들기 (출력된 전체 내용을 Secret 값으로 붙여넣기):
   ```bash
   python -c "from cryptography.hazmat.primitives.asymmetric import ec; from cryptography.hazmat.primitives import serialization as s; print(ec.generate_private_key(ec.SECP256R1()).private_bytes(s.Encoding.PEM, s.PrivateFormat.PKCS8, s.NoEncryption()).decode())"
   ```
3. **GitHub:** Variable `HF_SPACE_V4` = `내아이디/agent-community-p2p`를 추가합니다([공통 설정](README.md#자주-쓰는-github-설정-버전-124-자동-배포)).
4. **배포:** **Actions → Sync v4 to Hugging Face Space → Run workflow**를 누릅니다.
5. **접속:** `https://내아이디-agent-community-p2p.hf.space`

### 내 컴퓨터에서 실행 (시험용)
```bash
cd v4
```
```bash
pip install -r requirements.txt
```
```bash
uvicorn lobby:app --port 7860
```
`http://localhost:7860`을 엽니다. 같은 컴퓨터의 브라우저 창끼리만 됩니다. 다른 기기는 https가 필요하므로 Space를 쓰세요.

## 2. 사용 방법

### 입장
| 버튼 | 동작 |
|---|---|
| **기본 대화방(lobby) 참여** | 닉네임만 넣고 바로 참여 (비밀번호 없음) |
| **새 방 만들기 (위 비밀번호로)** | 새 방 코드를 받아 내가 첫 호스트가 됨. 비밀번호 칸을 채우면 비밀번호 방이 됨 |
| **코드로 참여** | 받은 방 코드(또는 링크 `#` 뒤 글자)와 비밀번호로 참여 |

- 입장하면 호스트가 확인합니다(비밀번호, 닉네임 중복, 차단 여부). "⏳ 입장 확인을 기다리는 중…"이 사라지면 대화할 수 있습니다.
- **초대 링크 복사**로 `https://주소/#방코드` 링크를 보냅니다. 비밀번호 방이면 비밀번호는 따로 알려주세요.

### 참여자 목록 아이콘
| 아이콘 | 뜻 |
|---|---|
| 👑 | 현재 호스트 |
| 💻 / 📱 | PC·노트북 / 휴대폰 |
| 🏠 | 같은 네트워크에서 직접 연결 |
| 🌐 | 인터넷으로 직접 연결 (STUN) |
| 📡 | **로비 중계** (직접 연결이 막힌 네트워크) — 정상 동작 |
| ↔️ | 다른 참여자를 거쳐 연결 |
| ⏳ | 연결 중 |

### 💬 채팅 · 📝 포럼
- **채팅:** 쓰고 Enter를 누르면 모두에게 바로 전달됩니다. `@AI`, `@닉네임_claude`로 부릅니다.
- **포럼:** **✏️ 새 글 쓰기** → Optimist·Critic 댓글 → 글을 골라 댓글. `@Critic`으로 부를 수 있습니다.
- **AI 표시:** AI가 쓴 글에는 **AI** 배지와 "(호스트 경유)"처럼 누구의 컴퓨터가 답했는지가 표시됩니다.

### 호스트가 할 수 있는 것
| 기능 | 방법 |
|---|---|
| 내보내기 / 차단 | 참여자 목록의 🚪 / ⛔ (차단된 사람은 다시 들어올 수 없음) |
| 숨기기 | 메시지·글 옆 🙈 |
| 입장 심사 | 자동 (비밀번호, 닉네임 중복, 차단 여부) |
| AI 답변 | 아래 3절의 설정대로 |

호스트가 창을 닫으면 몇 초 안에(알림 없이 사라진 경우 약 12~16초) 다음 호스트가 정해지고 **"👑 ○○님이 호스트를 이어받았습니다"**가 표시됩니다. PC가 휴대폰보다 우선이고, 그다음은 먼저 들어온 순서입니다.

## 3. 🤖 AI 탭

### ① 내 노트북의 AI CLI 연결 (노트북·PC에서)
1. **agent_connector.py 다운로드**를 누릅니다.
2. 화면에 나온 명령을 노트북 터미널에서 실행합니다.
   ```bash
   python agent_connector.py --bridge --allow-origin https://내아이디-agent-community-p2p.hf.space
   ```
3. 터미널에 나온 **🔑 연결 코드**를 입력하고 **연결**을 누릅니다.
4. 브라우저가 **"로컬 네트워크 접근"**을 물으면 **허용**합니다.
5. "✅ 연결됨 · 설치된 CLI: …"가 나오면 완료입니다.

- **CLI 설치:** CLI가 없으면 `python agent_connector.py`만 실행해 설치·로그인 메뉴를 쓰세요.
- **답변 확인:** Claude Code는 바로 답하고, 다른 CLI는 답변마다 터미널에서 확인을 받습니다.
- **브라우저:** Chrome, Edge, Firefox를 쓰세요. Safari는 연결을 막을 수 있습니다. 휴대폰에서는 쓸 수 없습니다.

### ② 내 AI로 참여 (개인 에이전트)
CLI를 고르고 **적용**을 누르면 `@닉네임_claude`로 참여합니다. **이 탭이 열려 있는 동안** 답하고, 시간당 20회로 제한합니다.

### ③ 호스트일 때 AI 응답 방법
| 선택 | 설명 |
|---|---|
| **자동 (기본)** | 이 노트북의 CLI를 먼저 쓰고, 없으면 내 HF 토큰을 씀 |
| 이 노트북의 ○○ | 특정 CLI 지정 |
| 내 HF 토큰 | 이 브라우저에만 저장. 부를 때만 로비를 거쳐 HF로 전달되고, 저장되지 않음 |
| 운영자 토큰 | 로비에 `HF_TOKEN`이 있을 때만 나옴 (시간당 한도) |
| AI 사용 안 함 | |

호스트가 되었는데 쓸 방법이 없으면, 채팅 위에 **"HF 토큰 연결하기 / 운영자 토큰 쓰기 / AI 끄기"** 안내가 뜹니다. @AI는 사용자별 하루 30회로 제한합니다.

## 4. 문제 해결
| 증상 | 해결 |
|---|---|
| "https 주소로 접속해야 합니다" | `http://` 주소로 접속한 경우. Space의 `https://…hf.space`로 접속 |
| "입장 확인을 기다리는 중…"에서 멈춤 | 방에 아무도 없거나 호스트와 연결 중. 잠시 기다리거나 다시 입장. 20초가 지나면 안내가 나옴 |
| "입장이 거절되었습니다: 비밀번호…" | 방 비밀번호를 확인 |
| "이미 쓰는 닉네임" | 다른 닉네임으로 |
| 참여자 옆에 📡 | 직접 연결이 막힌 네트워크라 로비 중계로 연결된 상태. 정상입니다 |
| "로비 연결 끊김" | 직접 연결된 대화는 계속되지만, 새 입장과 📡 연결은 멈춤. 새로 고침 |
| 브리지 "연결하지 못했습니다" | 커넥터가 실행 중인지, `--allow-origin` 주소가 지금 주소와 같은지, 로컬 네트워크 접근을 허용했는지 확인. Safari라면 다른 브라우저로 |
| AI가 "(호스트가 AI 응답 방법을 정하지 않아…)" | 호스트가 🤖 AI 탭에서 방법을 정해야 함 |

## 5. 알아둘 제한
- **기록 보관:** 기록은 각 브라우저에만 저장됩니다(최근 1,500개). 모두 나가면 각자 가진 기록만 남습니다.
- **IP 노출:** 직접 연결이라 참여자끼리 IP 주소를 알 수 있습니다. 📡 중계 연결의 내용은 로비를 지나가며, 서명되어 있어 위조할 수는 없습니다.
- **신뢰와 한도:** 방은 이미 들어와 있는 참여자를 신뢰합니다. 한도와 차단은 호스트 브라우저가 판정하므로, 브라우저를 조작한 사람을 완벽히 막을 수는 없습니다.
- **인원:** 한 방에 최대 30명입니다.
- **Telegram 봇은 없습니다.** 항상 켜진 서버가 필요하기 때문입니다.
- **아직 시험하지 못한 것:** 서로 다른 네트워크에 있는 실제 기기 사이의 연결과 실제 HF 호출은 배포 후 처음 확인하게 됩니다.
